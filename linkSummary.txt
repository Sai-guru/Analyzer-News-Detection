┌─────────────────────────────────────────────────────────────────────────────┐
│                          📱 FRONTEND WORKFLOW                               │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  1️⃣  USER INPUT                                                             │
│     └─> User enters a website URL in the input form                         │
│     └─> Form validation ensures URL is provided                             │
│                                                                             │
│  2️⃣  HTTP REQUEST                                                           │
│     └─> On submit, sends POST request to backend API                        │
│     └─> Endpoint: /api/summarize/website                                    │
│     └─> Body: { url: "https://example.com" }                                │ 
│                                                                             │
│  3️⃣  SSE STREAM HANDLING                                                    │
│     └─> Uses ReadableStream API to read response chunks                     │
│     └─> TextDecoder converts binary data to text                            │
│     └─> Parses "data: {chunk}" lines from SSE format                        │
│     └─> Accumulates chunks into complete summary                            │ 
│                                                                             │
│  4️⃣  REAL-TIME RENDERING                                                    │
│     └─> React state updates with each incoming chunk                        │
│     └─> AnalyzerDisplay renders markdown using react-markdown               │
│     └─> User sees summary being "typed" in real-time                        │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐

│                          🖥️  BACKEND WORKFLOW                               │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  1️⃣  REQUEST HANDLING                                                       │
│     └─> Express receives POST request at /api/summarize/website             │
│     └─> Extracts URL from request body                                      │
│     └─> Validates URL format (must be http:// or https://)                  │
│                                                                             │
│  2️⃣  WEBSITE FETCHING                                                       │
│     └─> Uses node-fetch to GET the target website                           │
│     └─> Sets User-Agent header to mimic browser request                     │
│     └─> 30-second timeout via AbortController                               │
│                                                                             │
│  3️⃣  HTML PARSING (JSDOM)                                                   │
│     └─> Parses raw HTML into DOM structure                                  │
│     └─> REMOVES: <script>, <style>, <nav>, <header>, <footer>               │
│     └─> EXTRACTS: Content from <main>, <article>, .content, or <body>       │
│     └─> Cleans whitespace and returns plain text                            │
│                                                                             │
│  4️⃣  CONTENT PREPARATION                                                    │
│     └─> Validates extracted text (minimum 50 characters)                    │
│     └─> Truncates to 50,000 characters if too long                          │
│     └─> Prepares prompt with structured instructions                        │
│                                                                             │
│  5️⃣  AI SUMMARIZATION (OpenRouter)                                          │
│     └─> Sends text to OpenRouter API                                        │
│     └─> Model: liquid/lfm-2.5-1.2b-instruct:free                            │
│     └─> Requests streaming response for real-time output                    │
│                                                                             │
│  6️⃣  SSE STREAMING RESPONSE                                                 │
│     └─> Sets headers: Content-Type: text/event-stream                       │
│     └─> Streams each AI token as: data: {"chunk": "..."}\n\n                │
│     └─> Sends done signal when complete                                     │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
